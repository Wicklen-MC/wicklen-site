Новый готовый профиль

Опубликованный профиль содержит Wicklen 0.6.0 и оформление. После импорта обязательно установите патч 0.6.0 → 0.7.0 для входа на текущий сервер.

  1. Скачайте файл .mrpack.
  2. Импортируйте его в Prism Launcher или Modrinth App.
  3. Выберите Java 25. Для компьютера с 16 ГБ памяти начните с 6 ГБ для игры.
  4. Установите патч Wicklen 0.6.0 → 0.7.0, объединяя папки с профилем.
  5. Запустите профиль: наборы ресурсов уже включены в нужном порядке.
Профиль .mrpack

131 клиентский JAR: 124 из основной сборки и 7 визуальных дополнений. Minecraft и внешние файлы загружаются при импорте.

Дополнить свой клиент

Необязательный визуальный ZIP для Wicklen 0.7.0. Если основной клиент старее, сначала обновите его до 0.7.0. Внутри уже лежат семь дополнительных модов, Reimagined и пресет Wicklen.

  1. Закройте игру и скачайте ZIP.
  2. Скопируйте папки mods и resourcepacks из архива в папку своего профиля Wicklen.
  3. Запустите игру и включите наборы ресурсов по порядку ниже.

Около 43 МБ. Сайт подготовит архив из официальных файлов; дополнительная установка программ не требуется.

Если раньше ставили другие версии этих визуальных модов, сохраните их отдельно, чтобы в mods не осталось двух версий одного мода.

Перед установкой

Нужно ли менять сервер или основной клиент?

Это необязательное оформление. На сервере идёт установка Wicklen 0.7.0. Если импортировали готовый профиль Reimagined на основе 0.6.0, перед входом обязательно установите патч 0.6.0 → 0.7.0. Визуальное дополнение можно сохранить.

Есть ли текстуры для всех наших модов?

Нет. Используется встроенная поддержка Reimagined там, где она есть. Остальные модовые блоки и предметы сохраняют собственные текстуры; для серверных предметов остаётся Wicklen Polymer.

Нужны ли OptiFine или шейдеры?

Нет. Набор собран для Fabric, а скриншоты сняты без шейдеров. Дополнительные анимационные и шейдерные паки в этот вариант не включены.

Как вернуть обычное оформление?

В новом профиле можно вернуться к своему старому профилю. В существующем клиенте отключите Reimagined и пресет Wicklen; для полного удаления визуальных модов используйте точный список в visual.lock.json, сохранив основной набор.
